## 外部事项的处理

许可不清楚的上游没有复制或启用；本轮不需要先拿到那些仓库的授权才能运行独立实现。没有向作者发送消息。未来若决定复制其代码，仍需核对许可。若决定分发产品，再确定项目自身许可和 PyMuPDF 许可路线；没有擅自替用户选择开源许可证。

其他模型 Provider 只有协议测试，未逐一做真实账号验收。自动脱敏可能有遗漏；结构和引用校验不等于模型语义判断正确，最终由面试官复核。
