## 真实模型

用户在本机设置页保存 DeepSeek Key，并确认允许使用合成简历进行少量调用。

- Provider：DeepSeek，Model：deepseek-flash，Base URL：https://api.deepseek.com。
- 连接测试：HTTP 200。
- 提纲生成：HTTP 201；5 个能力、4 个声明、2 个问题。
- 单轮回答分析：HTTP 200；返回 follow_up；声明更新与回答引文入库。
- 人工复核、结束面试、Markdown 报告：HTTP 200。
- 本地记录：项目 #2 / 候选人 #2 / 提纲 #3 / 会话 #1。全部标注合成测试资料。

首次尝试出现原文引用改写和能力名称不一致，系统拦截，没有存成成功提纲。已补充明确的数据合同和一次有上限的修正重试，最终真实调用通过。没有放宽引用必须来自原文的规则，也没有把示例输出冒充模型结果。
